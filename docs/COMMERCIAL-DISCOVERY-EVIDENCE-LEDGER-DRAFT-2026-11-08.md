## Transfer from ACMA: method, not performance claim

ACMA v0.4.1 observed speed increases in 101/111 tracks; v0.4.2 within-route mean excess -0.081; v0.4.3 matched mean excess -0.044 (74/111 tracks, 64 receivers), turn/excess r=+0.025. This is a **research-method example** showing how controls change interpretation. It is not evidence of AIAR buyer demand, reviewer-time improvement, verified human benefit, or an NFL acceleration mechanism.

Suggested *separate* case-study record fields: source notebook version and SHA-256, data selection, code/run identity, initial claim, counter-hypotheses, controls, exclusions, matched/unmatched counts, null/negative outcome, independent reproduction state, and limitations. Never copy licensed/private NFL data into AIAR.

## Verification classes (provisional, orthogonal to claim type)

- **E0:** unverified hypothesis/assertion.
- **E1:** attributed source or reported observation, exact evidence pointer.
- **E2:** reproducible synthetic/fixture test with code and run receipt.
- **E3:** directly inspected real-data calculation with dataset identity, selection, code and exclusions.
- **E4:** independent held-out/external evaluation of the *specific claim*.
- **E5:** independent replication under pinned protocol.

These are internal provenance/verification descriptors, not trust scores, legal certification, authenticity guarantees, or interchangeable with **commercial**, **human-study**, **institutional**, or **technical** evidence. A hash establishes byte identity, not truth. An image edit detector cannot prove a file unedited. Existing external-evidence/C2PA reference design remains authoritative; do not duplicate its schema.
